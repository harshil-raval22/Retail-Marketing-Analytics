# Retail Marketing Analytics Dashboard

## Project Overview
This project is an end-to-end retail and marketing analytics project built using Python, SQL, and Power BI. It analyzes sales, profit, customer behavior, and product performance to generate business insights.

## Tools Used
- Python
- Pandas
- Matplotlib
- SQL (SQLite)
- Power BI
- GitHub

## Workflow
1. Data Collection using Superstore dataset
2. Data Cleaning using Python
3. Exploratory Data Analysis (EDA)
4. SQL Business Analysis
5. Power BI Dashboard Creation
6. Business Insights Generation

## Key Dashboard Insights
- Monthly sales trend analysis
- Region-wise sales performance
- Category-wise sales and profit
- Top selling products
- Customer segment analysis
- Discount vs profit impact
- Interactive filters using slicers

## Files Included
- clean_data.py
- eda.py
- load_to_sql.py
- sql_analysis.py
- cleaned_superstore.csv
- superstore.db
- Power BI Dashboard (.pbix)

## Outcome
This project demonstrates end-to-end data analytics workflow from raw data cleaning to dashboard visualization and business decision insights.
